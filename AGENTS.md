# Instruções para assistentes de IA (Codex, Copilot, Cursor e outros)

Antes de qualquer coisa, leia **`CONTEXTO-DO-PROJETO.md`** (na raiz deste repositório). Ele explica o projeto, onde cada parte roda, como publicar, as regras do dono e onde paramos.

Regras curtas (detalhes no arquivo de contexto):
- Responda em português do Brasil, de forma simples: o dono não é programador.
- Tudo que for publicado na Cloudflare também precisa ir para o GitHub (`main`), inclusive o código dos Workers (`portal-worker.js`, `ai-worker.js`).
- Nunca coloque senhas, chaves ou dados de clientes no repositório: ele é público.
- No fim da sessão, atualize as seções "Onde paramos" e "Histórico" do `CONTEXTO-DO-PROJETO.md`.
